# /ars-watch

Run this user-invoked literature update when you explicitly ask. Provide a topic, date window, alerts, source
queries, or an optional workspace. Report direct changes, source/version updates, adjacent
work, failed checks, and what was not covered.

Ask before appending records, changing dates, or creating a recurring alert. A saved protocol
is useful context, not a prerequisite.
