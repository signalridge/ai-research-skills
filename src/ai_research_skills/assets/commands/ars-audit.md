# /ars-audit

Run an explicit, user-invoked adversarial and integrity review of a research answer, draft, corpus, or
brief. Try counterevidence, alternate terminology, citation/key mismatches, unsupported
numbers, and claims stronger than their sources. Search only if the request authorises it.

Return findings with artifact locations, failed refutation attempts, and practical follow-ups.
This is a report, not an automatic delivery block.
