# Discovery card — optional

Use this card when the user asks to discover literature. Combine the source methods that fit
the question rather than treating any fixed list as a requirement:

- several query phrasings and synonyms;
- citation or related-work links from supplied seeds;
- a venue, author, repository, or date search;
- a deliberately opposing or contrarian query; and
- the user's own sources or manual leads.

Record the query, source/tool, date, result boundary, and failures. A missing backend is a
reported coverage limit, not an excuse to invent results. Deduplicate by stable identifier and
keep unresolved candidates visible when they could change the answer.
