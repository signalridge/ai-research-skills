# Comparison card — optional

When the user asks for a map, compare the selected distinctions and show both occupied and
unknown areas. A coverage file may contain a partial or informal map; there is no required
Cartesian grid.

For each apparent gap, distinguish:

- not searched;
- searched but inconclusive;
- attempted with a limitation; and
- explicitly contradicted or covered.

Use nearby prior work and trend evidence when available. An empty cell is not evidence that
nobody tried. Preserve existing maps and legacy phase annotations unless the user asks for a
rewrite.
